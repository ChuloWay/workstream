Eight reads inspect bounded custody facts; one explicit reasoned mutation retries an exact verification job. Backend AUTH/ART remains the only authority and lifecycle owner.

## Intent and existing boundary

The #611 public API-to-CLI gap leaves artifact diagnosis and recovery inaccessible from the shipped client. Backend [AUTH-ART-02D-OPERATOR](../WS-AUTH-001/WS-AUTH-001-ART02DOPERATOR.md), merged by #650, now supplies persisted exact system-Operator authority and an independently guarded retry on the existing nine routes. Read success is an observation, never authority for a later retry. The Go client already provides one-shot bounded HTTP, strict response decoding, token-safe errors, terminal escaping, opaque continuation, and uncertain-write classification. There is no artifact Operator client yet.

The chosen design adds one `operations artifact` command family and a matching API owner that uses only `/api/v1/operator/artifacts`. It maps each route once, validates selected UUIDs and returned binding facts before output, and keeps server-owned states as observed strings rather than inventing client policy. Alternative raw-HTTP execution would bypass the typed client boundary; a client-side readiness/permission preflight would introduce a stale authority inference. Neither is adopted. No new human decision is required for these existing contracts.

## Acceptance and risk

All nine routes are reachable from one coherent command family with JSON and safe text output. Inputs with invalid UUIDs, resource enums, page limits/cursors, blank or oversized reason/key, or negative CAS fail locally without a request. Success decoding rejects malformed, extra, null-required, cross-resource or oversized output; no private/provider coordinates appear. Mutation uncertainty never causes an automatic second request. Existing commands and tests remain unchanged.

Risk: `L1` because the client exposes authorization-sensitive diagnosis and recovery, although it adds no authority. Human review focus: exact route coverage, resource binding and cursor handling, redaction, independent retry, one-shot uncertain-write behavior, and fresh real-API Operator proof. Run Go format/build/test/vet/mod verification, focused built-binary Python tests, and the final PR's hosted checks. The final CLI lead integrates shared docs and full journey proof before pushing/PR; no merge without explicit human approval.
