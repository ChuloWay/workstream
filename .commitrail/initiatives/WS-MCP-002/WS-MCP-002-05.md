# WS-MCP-002-05 - Actor and identity-link lifecycle

- Initiative: `WS-MCP-002`
- Durable disposition: `Complete`
- Intended merge outcome: Add five fixed public-API lifecycle tools to the independent MCP adapter.

## Intent

Let authorized human Access Administrators suspend, reactivate or permanently
deactivate actor profiles and revoke or reactivate identity links through MCP,
while Workstream remains the sole authorization, lifecycle and replay authority.

## Current behavior

Main at `123eb14b5` exposes five authoritative lifecycle operations in
`backend/app/modules/authorization/router.py`. The API owns token verification,
current authority, self and final-administrator guards, terminal deactivation,
current-state conflicts, idempotency, transactions and audit evidence. Before
this chunk, the merged adapter had eleven tools and no actor or identity-link
lifecycle bindings. This chunk raises the completed catalogue to sixteen tools.

## Design and decisions

Expose exactly `workstream_actor_suspend`, `workstream_actor_reactivate`,
`workstream_actor_deactivate`, `workstream_identity_link_revoke` and
`workstream_identity_link_reactivate`. Every input is closed and contains the
target UUID, a body with one 1-500 UTF-8 byte non-NUL reason, and a caller-supplied
UUID `idempotency_key`. The adapter forwards the caller bearer, body and key to
one fixed POST. HTTP headers and MCP metadata cannot provide or override the key.

Each call accepts only HTTP 200 and the operation-specific bounded receipt. The
receipt must identify the requested actor profile or identity link by UUID
identity, use the correct resource type and retain `version: null`. Explicit API
denials preserve only approved status/code/correlation data. Timeout, transport
failure, 5xx, unexpected success, malformed success or a foreign receipt after
dispatch returns `workstream_execution_uncertain`; the adapter never retries.
Recovery repeats the same arguments and key, including after adapter restart,
and Workstream returns the durable replay.

  reruns the installed-wheel journey.
